# Vunarc docs

Repository: [https://github.com/numdinkushi/Vunarc](https://github.com/numdinkushi/Vunarc)

The project overview, Arc usage, and hackathon submission notes live in the repository [README](../README.md).

Guides in this folder:

- [Architecture](ARCHITECTURE.md) describes wallet sign-in, roles, and the USDC payment split on Arc mainnet.
- [Arc payments](ARC_INTEGRATION.md) covers chain `5042`, `VunarcPayments`, and the buyer checkout flow.
- [Testing](TESTING_GUIDE.md) is the Arc mainnet test path. Testnet-only builds are not eligible for Arc Microgrants.
- [Security and withdrawals](SECURITY_AND_WITHDRAWALS.md) covers the payment secret and owner withdrawals.
- [Balance loading](BALANCE_LOADING_IMPLEMENTATION.md) covers the dashboard USDC balance states.

Older notes in this folder (PWA, image upload, product migration, farmer cards) describe those features only. They are not the payment or hackathon description.
